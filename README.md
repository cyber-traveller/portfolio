# Portfolio

A single-page personal portfolio built with React and Vite, with scroll-driven animation, a loading screen and a light/dark switch.

![React](https://img.shields.io/badge/React-19-61DAFB?logo=react&logoColor=white)
![Vite](https://img.shields.io/badge/Vite-646CFF?logo=vite&logoColor=white)
![GSAP](https://img.shields.io/badge/GSAP-88CE02?logo=greensock&logoColor=black)

## Sections

Hero, About, Skills, Projects and Contact, with an animated background and scroll sections.

## Tech stack

React, Vite, GSAP, Framer Motion, Tailwind CSS, styled-components, react-scroll, React Icons. Deployed on Netlify (`netlify.toml` included, with a single-page-app redirect).

## Getting started

```bash
git clone https://github.com/cyber-traveller/portfolio.git
cd portfolio
npm install
npm run dev
```

| Command | What it does |
| --- | --- |
| `npm run dev` | Start the dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview the build |
| `npm run lint` | Run ESLint |
